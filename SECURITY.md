# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue or pull request.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, the version or commit, and steps to reproduce.

You'll get an acknowledgement within a few days. Once a fix is ready, it's released and the report is credited in the advisory unless you'd rather stay anonymous.

## Supported versions

crawlmark is pre-1.0. Only the latest release gets security fixes.

## Scope

crawlmark runs on your own machine and reads your own credentials. Reports about how it handles untrusted input (crawled pages, imported files, API responses), local files and credentials, or paid API spend limits are all in scope.
